## About

Final-year B.Tech (Information Technology) student at BVM Engineering College, Gujarat — building production-grade AI systems with a focus on LLM integration, RAG pipelines, and local inference infrastructure.

Interned at **Mem0 AI**, where I shipped a voice-controlled local AI agent — combining faster-whisper for transcription, Ollama (llama3.2:3b) for inference, and Streamlit for the interface. My approach to AI engineering is grounded in making systems that work reliably in constrained, real-world environments, not just demos.

My strongest project, **AskBVM**, is a RAG chatbot for my college — built from scratch with LangChain, FAISS, FastAPI, React, and Ollama using nomic-embed-text embeddings. I've tuned every layer: hybrid retrieval with MMR, spell correction, similarity thresholds, keyword search, chunk sizing, and a full scraper pipeline with deduplication and two-level link traversal.

I work at the intersection of local and cloud LLM inference (Ollama for on-device, Groq + OpenAI for cloud), FastAPI for backends, and React for interfaces. Currently deepening hands-on AWS experience and reinforcing system design and MLOps fundamentals.

**Open to:** AI/ML Engineering · LLM Application Development · Generative AI · Full Stack AI Product Roles

> A production-grade RAG system that answers student queries about the college — faculty, syllabus, schedules, and campus info — using a full custom pipeline from scraping to response.

| Attribute | Details |
